# EVENTORA — frontend starter

## Run it
1. Extract this folder.
2. Open `frontend/index.html` in a browser, or open the `EVENTORA` folder in VS Code and use the Live Server extension.
3. Try search, category filters, event details, saved events, and demo registration.

The event listings are fictional sample data. Save and demo registration use browser `localStorage`; they are not yet connected to a database. Next we'll connect Flask + MySQL.

## Files
- `frontend/index.html` — page structure
- `frontend/style.css` — visual design and responsive styles
- `frontend/script.js` — search, filters, saved events, and event details
